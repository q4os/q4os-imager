# Security Policy

## Supported versions

Only the latest released version of Q4OS Imager is supported with security
updates.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by e-mail to
**devteam@q4os.org**. Do not open a public issue for security reports.

Include a description of the issue, steps to reproduce, and the affected
version and platform. You will normally receive an initial response within
7 days. Once the issue is confirmed and fixed we will publish an updated
release and credit the reporter, unless you prefer to remain anonymous.
