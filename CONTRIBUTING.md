# Contributing to Q4OS Imager

Thank you for your interest in improving Q4OS Imager.

- **Bug reports and feature requests**: please open a GitHub issue with steps
  to reproduce and details of your platform.
- **Pull requests** are welcome. Keep changes focused, describe what and why,
  and make sure the project still builds (Linux `debuild`, Windows via the
  GitHub Actions workflow).
- **Upstream-relevant fixes**: Q4OS Imager is a fork of Raspberry Pi Imager.
  Fixes that are not Q4OS-specific are best submitted to the
  [upstream project](https://github.com/raspberrypi/rpi-imager) so that
  everyone benefits; we periodically merge from upstream.
- **Security issues**: see [SECURITY.md](SECURITY.md) — please do not report
  them publicly.
- Contact: <devteam@q4os.org>
